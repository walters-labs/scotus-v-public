Search methodology

{% if info.get('hybrid_search') %}Court search: TF-IDF + embeddings. Keywords and meaning rank cases; a fixed relevance threshold selects chart matches.{% else %}TF-IDF ranks keyword matches; the chart uses a fixed relative relevance cutoff.{% endif %} Lists show up to ten cases and ten questions per survey source.{% if info.get('survey_topic_routing') %} Survey matching also uses reviewed topic labels where available.{% endif %} Matching is approximate and may miss relevant results or include unrelated ones.

Scores. −1 is conservative and +1 liberal. Court scores combine SCDB decision direction and vote margin, weighted by search relevance each year. They describe the coded decision, not necessarily support for the searched policy; procedural rulings can contribute too.{% if info.get('public_trends_enabled') %} Survey scores use documented answer mappings and respondent weights, then average question families equally; only one variant per family contributes each year.{% else %} Legacy survey scores use unweighted response-category order, including labeled missing answers.{% endif %} The two scales measure different things.

Trends. Combined opinion gives each available survey source equal weight. Lines connect observed years, breaking across gaps over five years; missing years are not estimated. Outlined dots and dashed segments indicate changes in sources or questions. Such changes can move the index without a change in opinion. This is an exploratory comparison, not evidence of causation.
