About this comparison

{% if info.get('hybrid_search') %}Court ranking combines semantic similarity with TF-IDF; surveys use TF-IDF.{% else %}TF-IDF ranks texts by keyword relevance.{% endif %} Court polarity combines SCDB decision direction with the vote margin. Survey polarity combines saved question orientations with yearly response averages. Lines connect measured annual averages; they do not estimate missing years or establish a causal relationship.

{% if info.get('public_trends_enabled') %}

Public scores use explicit answer mappings from −1 (conservative) to +1 (liberal), exclude missing answers, and use each question’s documented full-sample weight. One variant per question family contributes each year; family scores are averaged equally. Unchanged-policy answers are midpoint scores, not necessarily ideological centrism. Coverage varies by topic and year. Court scores are averaged using {% if info.get('hybrid_search') %}hybrid relevance weights across scored cases passing the displayed threshold{% else %}TF-IDF relevance weights across all scored cases meeting the fixed 20% relevance cutoff{% endif %} for each year; the two scales measure different things.

{% else %}

This dataset uses legacy unweighted survey category-order scaling (including labeled missing responses). Court scores are averaged using TF-IDF relevance weights across the scored cases retrieved for each year. These limitations can materially affect results; this is a historical exploratory project, not a validated public-opinion measure.

{% endif %}
